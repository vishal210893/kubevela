# KEP-2.13 Addon Drift Detection (ResourceTracker) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Addon CR explicitly track everything it installs (the owned Application plus the directly-applied auxiliaries) in an addon-owned ResourceTracker, heal deleted/edited resources from the stored manifests with no network call, and only run the network `install()` on a complete miss (no RT) or a version change.

**Architecture:** Mirror the Application controller's `StateKeep` (`pkg/resourcekeeper/statekeep.go:41`): store each managed resource's full manifest in a `v1beta1.ResourceTracker` owned by the Addon CR, then on steady-state reconciles re-apply each stored manifest through `apply.APIApplicator.Apply` (three-way merge with empty-patch short-circuit), which recreates deletions and reverts edits and no-ops when clean. The installer gains an object-sink InstallOption so the controller can capture exactly what was applied without a second fetch.

**Tech Stack:** Go, controller-runtime, KubeVela `v1beta1.ResourceTracker` / `ManagedResource`, `pkg/utils/apply`.

**Spec:** `docs/superpowers/specs/2026-06-22-kep-2.13-addon-drift-detection-design.md`

```go
const trackerOwnedByAddonLabel = "addon.oam.dev/owned-by"

// writeTracker creates or updates the addon's drift ResourceTracker with the
// given objects' manifests. The RT is owned by the Addon CR and carries the
// owned-by label so the Application RT garbage collector never claims it.
func (r *Reconciler) writeTracker(ctx context.Context, ad *v1beta1.Addon, objs []client.Object) error {
	mrs := make([]v1beta1.ManagedResource, 0, len(objs))
	for _, o := range objs {
		mr, err := managedResourceFrom(o)
		if err != nil {
			return err
		}
		mrs = append(mrs, mr)
	}
	rt := &v1beta1.ResourceTracker{ObjectMeta: metav1.ObjectMeta{Name: trackerName(ad.Name)}}
	_, err := controllerutil.CreateOrUpdate(ctx, r.Client, rt, func() error {
		if rt.Labels == nil {
			rt.Labels = map[string]string{}
		}
		rt.Labels[trackerOwnedByAddonLabel] = ad.Name
		rt.Spec.ManagedResources = mrs
		return controllerutil.SetControllerReference(ad, rt, r.Scheme)
	})
	return err
}

// loadTracker returns the addon's drift ResourceTracker, or nil if absent.
func (r *Reconciler) loadTracker(ctx context.Context, addonName string) (*v1beta1.ResourceTracker, error) {
	rt := &v1beta1.ResourceTracker{}
	if err := r.Get(ctx, client.ObjectKey{Name: trackerName(addonName)}, rt); err != nil {
		if apierrors.IsNotFound(err) {
			return nil, nil
		}
		return nil, err
	}
	return rt, nil
}
```
Add imports: `context`, `metav1 "k8s.io/apimachinery/pkg/apis/meta/v1"`, `apierrors "k8s.io/apimachinery/pkg/api/errors"`, `"sigs.k8s.io/controller-runtime/pkg/controller/controllerutil"`.

NOTE: `ResourceTracker` is cluster-scoped, matching the cluster-scoped Addon CR, so `SetControllerReference` (cluster→cluster) is valid.

```go
// healFromTracker re-applies every managed resource from the tracker, mirroring
// the Application controller's StateKeep: a deleted resource is recreated, an
// edited resource is patched back to the stored manifest, an unchanged resource
// no-ops. It never fetches from the registry. Errors are aggregated so one bad
// resource does not block the rest.
func (r *Reconciler) healFromTracker(ctx context.Context, rt *v1beta1.ResourceTracker) error {
	if rt == nil {
		return nil
	}
	applicator := apply.NewAPIApplicator(r.Client)
	var errs []error
	for i := range rt.Spec.ManagedResources {
		mr := rt.Spec.ManagedResources[i]
		if mr.Data == nil || mr.Data.Raw == nil {
			continue
		}
		obj, err := mr.ToUnstructuredWithData()
		if err != nil {
			errs = append(errs, fmt.Errorf("decode %s: %w", mr.ResourceKey(), err))
			continue
		}
		if err := applicator.Apply(ctx, obj, apply.DisableUpdateAnnotation()); err != nil {
			errs = append(errs, fmt.Errorf("re-apply %s: %w", mr.ResourceKey(), err))
		}
	}
	return errors.Join(errs...)
}
```
Add imports: `"errors"`, `"fmt"`, `"github.com/oam-dev/kubevela/pkg/utils/apply"`.

```go
type objectCollector struct {

func newObjectCollector() *objectCollector { return &objectCollector{} }
```

```go
			return ctrl.Result{}, perr
		}
		return ctrl.Result{RequeueAfter: r.interval()}, nil
	}
```
